- 全市场代理：债底覆盖（权重 **48%**，t=6.7，四年斜率全正 +0.33/+0.34/+0.22/+0.31，结构性规律、最强维度）
- 注意：v2.0 的"0.6×信用 + 0.4×债底"S3 合成**未在终稿采用**——终稿信用归 D1、债底独立 D3

**D4 正股走势与联动**
- A线正股三档映射：正面=8.5、中性=5.2、负面=2.0；催化与风险 ±0.5 修正

**D5 流动性与路径**
- 正股 120 日回撤分段（≤10%→9 … >25%→2.5）+ 成交中位数三分位 ±0.5
- 全市场代理：低换手（权重 **23%**，t=-4.6，四年全负——"换手=妖债温度计"）

**D6 市场表现预测**

## 三、权重：历史数据如何确定（对齐主PPT p05）

1. **输入**：799 只底层转债 × 43 个月末截面（每月约 399 只有效样本），剔除本组 18 券
2. **特征**：8 项，去极值、标准化
3. **标签**：未来 120 日收益；**回撤触及 −15% 时记为 −15%**（下行约束标签）
4. **方法**：Fama–MacBeth 月度截面回归（|平均系数|归一化）与 RankIC/ICIR（ICIR 取正部归一化）**两分支各占 50%**，按 D1–D6 加总 → 六维参考权重。D3 算例：(48.75% + 46.96%) ÷ 2 = 47.86%，展示为 48%
5. **诚实边界（以 p05 原文为准）**："权重为本期参考。t 值用于诊断，券池隔离不等于时间样本外验证，历史代理与单券打分输入有差别。"——主PPT p04/p33 所称"纯样本外"特指剔除本组 18 券的券池隔离口径
6. **载体**：`b-quant`（`results/weights/weights.json`、`fm_slopes.csv`、`rank_ic.csv`）；再生成与对账入口 `scripts/run_v6_scoring.py`
7. 与 v2.0 差异：v2.0 的"IC/ICIR 主方法 + FM 互证 + 等权对照"主次安排未按原文执行，终稿为两分支各 50%，等权对照仅作设计期稳健性讨论

## 四、红线与决策（对齐主PPT p03 / p32 / p33 / p35）

**三条红线（评分之外一票否决，触发即出局）**
- R1 评级下调 ×5：江山、艾录、火星、亿田、帝欧
- R2 转股溢价率 >100% ×6：金23、志邦、蒙娜、科沃、乐歌、嘉益
- R3 期限或样本不可评 ×2：乐歌（期内到期）、翔26（仅 61 条报价）
- 乐歌双踩（R2+R3），合计 **12 只**红线券；没踩红线的叫开放券

**两步决策**
1. **补偿入围**：树差 ≥0 且无红线 → 直接进推荐池（海顺 +4.91、莱克 +2.75）
2. **权重补位**：不足三席 → 非红线券按综合分补足（特纸 5.61，开放券第一）
3. **红线兜底**：评分再高也不入池（科沃综合 6.04 全池最高，仍被 R2 否决——"好公司≠好转债"的数字版）

**早停条款**（继承自 v2.0）：权重校准结果若推翻推荐名单（海顺/莱克/特纸）→ 停下来全组讨论。
