# 第13组研究框架 v2：研究架构与AB分工设计

**定位**：本文档是全组研究架构的总纲——先定框架与边界，再谈页面与建模。
**原则**：A组（6人，金融分析师方向）是**主体研究线**，产出投资判断；B组（4人，金融工程与量化方向）是**量化验证与增强线**，提供数据地基、方法论与统计证据。**凡涉及投资含义与判断的，归A；凡涉及数据实现与统计验证的，归B；判断与实现分离，互不替代。**

## 二、课程"分析内容参考"逐项归属

| 课程参考项 | 归属 | 理由 |
| --- | --- | --- |
| 行业分析 | **A主责** | 需求机制、产业链、政策传导是金融分析训练的核心产出 |
| 公司概况 | **A主责** | 业务结构、竞争位势决定一切后续判断 |
| 正股走势判断 | **A主责** | 基于行业/公司/财务/催化的**研究判断**（方向+逻辑+风险），是分析师核心能力 |
| 转债条款分析 | **A主责** | 下修/强赎/回售的博弈逻辑与发行人行为动机，判断密集区；B0仅提供公告事实核验 |
| 信用风险评估 | **A主责** | 偿债、现金流、评级变化的判断；B可提供市场隐含信号作佐证，但不替代判断 |
| 债底价值估算 | **AB协作（A定假设并解释，B实现计算）** | 折现公式简单，难在信用利差情景与条款处理的选择——这是金融判断；B负责实现与敏感性 |
| 估值指标分析 | **AB协作** | 溢价/平价等指标B统一计算；"贵不贵、为什么贵"的解释归A（必须结合正股基本面） |
| 期权价值评估 | **AB协作（B实现，A解释）** | B组建树与参数（专业优势）；"期权价值高=市场在赌什么、赌得可信吗"归A |
| 流动性考量 | **AB协作（B计算，A解释）** | 换手/成交/深度B算；"对六个月持有者意味着什么"（退出折价、炒作风险）归A |
| 市场表现预测 | **B主责** | 历史数据驱动的统计预测/排序，B组专业领地；A的基本面观点作为输入与合理性检验 |

**要点**：传统金融分析的四大主项（行业、正股判断、条款、信用）全部A主责——B不抢。B主责只有市场表现预测一项，加上两块服务性工作（数据地基、权重数据化）。**A的"正股走势判断"是研究判断（为什么会涨/跌），B的"市场表现预测"是统计预测（历史上类似状态下的分布）——前者给逻辑，后者给分布，互补不重复。**

## 三、工作结构：A组6人、B组4人

### A组：券负责制 + 横向认领（不做一人一维）

每人**纵深负责3只券**（覆盖全池18只），是该券基本面第一责任人，产出该券《基本面投资逻辑书》（一页纸：核心矛盾、正股走势判断、信用观点、条款要点、估值含义、初步倾向）。在此基础上每人**横向认领一项全池任务**，形成交叉覆盖与A组内部互审：

| 成员 | 纵深（3券） | 横向认领（全池） |
| --- | --- | --- |
| A1 | 券1/2/3 | 行业版图与跨行业需求比较 |
| A2 | 券4/5/6 | 信用风险横向基准（偿债/现金流跨券比较） |
| A3 | 券7/8/9 | 条款事件横向（全池下修/强赎/回售状态一览） |
| A4 | 券10/11/12 | 正股走势判断汇总（统一格式：方向/催化/风险） |
| A5 | 券13/14/15 | 估值含义横向（溢价/平价相对位置的投资解释） |
| A6 | 券16/17/18 | 流动性与交易含义横向（对接B的量化计算） |

券的分配应按行业就近（同链券归同一人，如陶瓷两券归一人），便于同业对照。

### B组：专业模块制（4人=4模块，自然分工非硬凑）

| 成员 | 模块 | 职责 | 现状 |
| --- | --- | --- | --- |
| B0 | 数据地基 | 采集/清洗/口径/哈希/供数接口/数据字典 | **已基本完成**；剩余：供数接口文档化、响应A的口径工单 |
| B1 | 定价与估值计算 | 债底折现、期权定价树、溢价/平价等全部估值数字的实现与敏感性表 | 方法已验证，需整理为A可直接引用的口径说明 |
| B2 | 评分与权重的数据化 | 特征构建、权重校准（第五节方案）、样本外验证与稳健性 | 已有实证管线与文献验证，按新框架对齐维度 |
| B3 | 市场表现预测 | 候选转债六个月相对表现/风险的分布预测与回测 | 已有块bootstrap+退出曲面+walk-forward原型 |

> 说明：B组按模块分工是因为这四块各自需要不同的专业栈（数据工程/定价/统计学习/时间序列预测），且B组人数少于维度数——**B不为覆盖而覆盖，B的每个模块都必须服务A的判断**（见第四节）。

## 四、B0/权重/预测如何服务A组（边界机制）

**B0 → 服务方式：供数与口径仲裁**
- A组永远不从行情软件抄数字：页面与报告的每个数字从B0统一面板取用，附来源字段；
- A发现口径问题→提工单→B0改源→全组一键重算（杜绝上一届串页事故的机制保障）；
- B0交付《数据字典》，让每位A成员知道每个字段的定义与局限。

**权重数据化 → 服务方式：B校准、A评审、A有一票否决**
- A组按统一映射规则给基本面维度打分；B2用历史数据校准各维度权重后，**提交A组评审**——答辩问题是"这个权重凭什么"，B2用单因子逻辑+样本外稳定性证据回应；
- 权重经A组采纳后才进入合成；若合成排名与A组基本面直觉冲突，触发**交叉修正会议**：或A修正打分依据、或确认评分体系盲区、或增设红线/修正项；
- **A保留一票否决权**：信用红线（评级下调/违约风险）不受权重影响——这是A组主体地位的机制保证。

**市场表现预测 → 服务方式：反馈而非决定**
- B3对18只券给出六个月收益分布（P5/P50/P95/P亏损）与相对排序；
- 三种反馈：(a) **校准**——A看好但模型分布差的券，必须过会说明分歧来源；(b) **风险量化**——P5与P(亏)作为A结论的下行风险参考；(c) **稳健佐证**——模型排序与A排序的一致性是体系稳健性检查；
- 预测进入综合评分的权重同样由B2校准，且模型不拥有最终决策权——最终决策是合成规则+A组红线。

## 五、"历史数据倒推权重"是否合理：三方案与推荐

**总判断：合理，且有学术依据，但有三个前提**——(a) 收益标签必须匹配委托（重视下行→用回撤约束收益，不用裸收益）；(b) 必须样本外验证（剔除本组标的、分年度稳定性）；(c) 承认权重是估计量，决策机制不能纯依赖排序。三个前提都有现成方法，过拟合风险可控。

### 方案一：IC/ICIR加权（推荐主方法）

每月计算各维度分数与下月收益（回撤约束口径）的秩相关IC；权重∝mean(IC)/std(IC)，负IC维度权重归零并说明理由。
- 可解释性：★★★★★ "预测力×稳定性"一句话讲清；负IC归零有明确含义（该维度历史上不预测收益，其投资含义由红线/修正项承担）
- 数据可得性：★★★★★ 只需本组已有的面板与打分
- 过拟合风险：中——43个月短样本下各维度ICIR差异统计不显著，需诚实报告并配合决策端兜底
- 出处：Grinold & Kahn《Active Portfolio Management》；Qian-Hua-Sorensen《Quantitative Equity Portfolio Management》

### 方案二：Fama-MacBeth回归斜率加权（互证方法）

月度截面多元回归取斜率均值→归一化为权重。
- 可解释性：★★★☆ 控制特征间共线性、给出t值；但斜率语义是"因子溢价"而非"预测力"，共线维度符号易翻
- 数据可得性：★★★★★ 同上
- 过拟合风险：中高——短样本+共线，斜率不稳
- 定位：与方案一互证（两法权重排序一致才采用），不单独作主方法

### 方案三：等权+敏感性区间（稳健性基线）

六维等权，报告权重扰动下结论的稳定性。
- 可解释性：★★★★ "我们不设定权重"本身是最强的可解释性
- 过拟合风险：★ 几乎为零（DeMiguel等2009：1/N是难以击败的稳健基线）
- 缺点：放弃已知预测力差异，量化增强含量低

### 推荐：组合拳

**方案一为主权重 + 方案二互证（两法排序一致才采信）+ 方案三作稳健性对照 + 决策端"补偿门槛+信用红线"兜底**。理由：可解释性（每一步有出处）、数据可得性（面板已在手）、过拟合控制（样本外剔除+分年度稳定性+两步法不押注权重精度）三者兼顾；且"门槛看绝对补偿、排序用估计权重"的分工使权重噪声不影响最终名单的正确性。

## 六、评分维度重设（粗粒度）

从课程参考项与AB边界重新推导（不沿用旧结构），得**6个评分维度+2个机制**：

| # | 维度 | 内容 | 打分者 | 权重来源 |
| --- | --- | --- | --- | --- |
| S1 | 基本面质量 | 行业位置+公司经营+盈利与现金质量 | A（按统一映射规则打分） | 数据校准 |
| S2 | 正股走势判断 | A的研究判断：方向（正面/中性/负面）+催化+风险，三档映射成分 | A | 数据校准 |
| S3 | 信用与安全垫 | A的信用档位（含降级风险）+ B的债底覆盖率合成 | A定档，B计算 | 数据校准 |
| S4 | 估值与兑现 | 溢价率、平价位置、期权价值占比（B计算，A解释含义） | 规则统一打分 | 数据校准 |
| S5 | 路径与流动性 | 回撤、换手、成交（B计算；A解释持有含义） | 规则统一打分 | 数据校准 |
| S6 | 市场表现预测 | B的六个月分布预测：中枢/尾部/亏损概率 | B（模型直接产出） | 数据校准 |
| M1 | 条款博弈修正项 | 下修/强赎/不赎回/回售事件按A的博弈逻辑加分或减分（如"已承诺不下修"减分） | A | 固定小幅度（±1内），不参与权重校准 |
| M2 | 信用红线 | 评级下调/违约风险/溢价不可承保/期限样本不可评 → 一票否决 | A | 否，红线无权重 |

## 七、完整流程：候选池 → 3推荐+3不推荐

```
阶段0  地基（B0，已完成大半）
       18券统一面板 + 数据字典 + 口径基准 + SHA清单
          │
阶段1  A独立分析（六人并行，2周）
       每人3券《基本面投资逻辑书》+ 横向认领
       产出：S1打分、S2正股判断、S3信用档、条款事件清单（M1素材）
          │
阶段2  B量化计算（与阶段1并行）
       B1：债底/期权/溢价全池数字+敏感性 → 供A引用
       B2：全市场面板 → 维度权重校准（附样本外证据）→ 提交A评审
       B3：18券六个月分布预测（先出初步版）
          │
阶段3  交叉修正（第一次合流会）
       ① A评审权重：质询→答辩→采纳
       ② B3反馈：A看好但分布差的券逐一过会（或A修正、或标注分歧保留）
       ③ 条款事件：B0给事实时间轴，A定博弈含义（M1修正项定稿）
       ④ A定稿信用红线（M2）
          │
阶段4  综合评分与决策
       全池打分（S1-S6）→ M1修正 → 市场权重加权合成 → 开放券排序
       → 两步法：补偿门槛入围 + 权重排序补足 → 候选3推荐
       → 红线复核 → 候选3不推荐（附改判条件）
          │
阶段5  终审与交付（第二次合流）
       全组交叉review（每人审核非自己负责的券，数字溯源表逐格核对）
       → 学术报告 + 课堂PPT + 成员文件夹（任务说明/数据溯源/讲稿）
       → 3推荐（附条件）+ 3不推荐（附红线与改判条件）
```

**冲突处理规则**（预写进流程，避免临时扯皮）：
1. A判断与模型分布冲突 → 过会，双方各自给证据；无法说服则标注分歧、按合成规则执行、在报告中保留分歧记录；
2. 权重校准结果推翻推荐名单 → 停下来全组讨论（这是权重的早停检查点）；
3. 数据口径争议 → B0仲裁，以公告原文为准；
4. 信用红线由A组集体确认，B组不参与否决投票，但必须提供市场隐含信号的量化佐证。

## 八、本框架与旧版（v1评分版）的差异说明

| 项 | v1（已建） | v2（本框架） | 原因 |

**已建资产的去向**：B0面板、定价与预测原型、权重估计管线、实证结论（债底保护四年全正、低溢价归零）全部平移进入v2框架的对应模块；需要重做的是维度映射表（新增S2、M1）与A组打分表——工作量可控。
