# 维度体系章程（全组口径 ·一经A组确认即为最终）

**地位**：本文档是权重估计与评分合成的前提——"研究哪几个方面"先钉死，"求谁的权重"才有对象。任何维度增删、映射常数修改须经全组确认并更新版本号。

## 一、六个评分维度

### S1 基本面质量
- **内容**：行业位置、经营质量、盈利与现金质量（不含信用资质——那是S3）
- **打分者**：A（券负责人，按统一映射）
- **打分规则**：direction前缀映射——正向=8.8、中性偏正=6.5、中性=5.2、中性偏负=3.5、负向=1.0
- **应用端数据**：work/A/results.csv · direction（财报PDF人工核验）
- **全市场代理**：偿债能力（Qty_EquitytoAssets）+ 盈利水平（Qty_ROE）
- **权重预期**：低（实证中偿债/评级类代理弱显著）——A判断的价值主要走S3与红线

### S2 正股走势判断（A组研究判断，本版新增）
- **内容**：基于行业、公司、财务与催化的**研究判断**，三要素格式：方向（正面/中性/负面）+ 催化剂 + 风险
- **打分者**：A（券负责人；A4横向汇总成全池可比格式）
- **打分规则**：方向三档映射——正面=8.5、中性=5.2、负面=2.0；催化与风险作为±0.5修正（在维度章程内，不进权重校准）
- **应用端数据**：**待A4汇总填入**（work/A/S2_正股走势判断.csv，当前为中性占位5.2，已声明）
- **全市场代理**：业绩动量（Qty_NetProfitsGrowth，缩尾）——诚实声明：A的判断本身无法全市场复现，校准的是"基本面判断维度在市场定价中的价值"
- **与B的市场表现预测（S6）的边界**：S2给逻辑与方向（为什么会涨跌），S6给分布（历史上类似状态的统计结果）

### S3 信用与安全垫
- **内容**：信用档位（评级、降级风险、偿债）+ 债底对市价的保护
- **打分者**：A定信用档，B计算债底覆盖；合成规则固定
- **打分规则**：S3 = 0.6×信用分 + 0.4×债底覆盖分。信用分：AAA=9.8、AA+=9.0、AA=8.5、AA-=7.5、A+=6.0、A=4.5、BBB+=3.0，降级扣1.5；债底覆盖分：真实现金流折现债底(200bp)÷市价 分段映射（≥1.05→10 … <0.7→2）
- **应用端数据**：work/A/results.csv · rating/rating_previous；work/B_methods/B2/results.csv · debt_floor_200bp；B1/base.csv · bond_close
- **全市场代理**：评级序数 + 债底覆盖（保本价/市价）——实证：债底覆盖四年斜率全正（NW t=6.8），是权重最高的维度

### S4 估值与兑现
- **内容**：转股溢价率、平价位置、树差（期权价值偏离）
- **打分者**：B计算，规则统一（A解释投资含义）
- **打分规则**：溢价分段（≤20%→9.5 … >150%→0.5）+ 树差修正（溢价≤80%时 clamp(树差,±3)×0.4；高溢价时树差为虚值期权价值不计入）
- **应用端数据**：work/B_methods/B1/base.csv · conversion_premium_pct；work/B_methods/B2/results.csv · tree_gap_pct
- **全市场代理**：低溢价（-转股溢价率）；分解残差仅作诊断（逐年不稳）
- **权重预期**：≈0（逐年翻符号）——溢价的投资含义由M2红线（>100%不可承保）承担

### S5 路径与流动性
- **内容**：持有路径风险与交易退出条件
- **打分者**：B计算，规则统一（A解释持有含义）
- **打分规则**：正股120日回撤分段（≤10%→9 … >25%→2.5）+ 成交中位数三分位±0.5
- **应用端数据**：data/curated/b_daily 面板
- **全市场代理**：20日回撤 + 对数换手（低换手四年全负，t=-4.3，第二强维度）

### S6 市场表现预测
- **内容**：未来六个月收益分布（P50/P5/P亏损），块bootstrap×退出曲面
- **打分者**：B3模型直接产出（0.4×P50映射 + 0.3×P5映射 + 0.3×亏损概率映射）
- **应用端数据**：b-quant/results/predict/predictions.csv（bootstrap/convergence/200bp）
- **全市场代理**：历史窗口损失频率（120日窗口收益<-10%的占比，取负）
- **权重预期**：中低（校准72%覆盖率已声明区间偏窄）

## 二、两个机制（无权重或固定小幅）

### M1 条款博弈修正项（固定±1内，不参与权重校准）
- **打分者**：A（条款博弈逻辑；B0提供公告事实时间轴）
- **规则**：已公告不下修→-0.5；不赎回承诺期覆盖不满六个月→-0.5；回售保护期→+0.5；预计触发下修（未决议）→0（下修权在发行人）。封顶±1
- **素材**：work/B_methods/B1/events.csv（30条公告）

### M2 信用红线（A一票否决，无权重）
- R1 评级下调（江山/艾录/火星/亿田/帝欧）；R2 转股溢价率>100%（正股需涨一倍以上才可兑现：金23/志邦/蒙娜/科沃/乐歌/嘉益）；R3 期限或样本不可评（乐歌期内到期、翔26仅61条）
- 触发即出局，评分再高不入推荐池；附改判条件

## 三、合成与决策

综合分 = Σ(Sᵢ × wᵢ)，wᵢ由全市场799只转债、43个月度截面反推（IC/ICIR主方法 + Fama-MacBeth互证 + 等权对照；标签为-15%止损约束收益；估计样本剔除本组18只）。决策两步法：补偿门槛（树差≥0且无红线）直接入围推荐池 + 市场权重综合分补足第三席。权重校准结果若推翻推荐名单（海顺/莱克/特纸）→ 早停，全组讨论。
