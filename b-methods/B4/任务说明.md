# B4｜情景敏感性、模型边界与交叉复核

**交给这位成员的完整任务：**把B1价格结构、B2相对定价和B3下行风险放在同一投资问题下质询：结论依赖什么假设，什么变化会使它反转？你负责模型透明性与反方检验，不是替三人平均打分。

**已有起点：**运行 `python work/B_methods/B4/run.py`，得到[`scenario_v1.csv`](scenario_v1.csv)和[维持当前债价所需溢价图](required_premium_sensitivity_v1.png)。18券逐一计算正股价上下20%时的转股价值、若债价不变所需溢价，以及**假设**溢价压缩10个百分点时的机械价格敏感性。这是代数情景，不是公平价值或未来价格预测；目前仍使用B1未获公告生效日签认的候选转股价。

先读[负责人预研观察](../负责人预研观察-v0.md)与[B1真实公告核验样板](../B1/公告核验样板.md)。前者提供可挑战的冲突，后者说明科沃、帝欧、亿田的公告事件为何会改变情景解释；这些都未替代你对原始公告和计算的复核。

把逐券交叉质询写入[18券冲突复核表 v0](逐券冲突复核表_v0.csv)，完成后另存 v1 并署名；即使某券没有明显冲突，也要写为什么当前方法可用或应降级。

**你要做的工作：**

1. 逐券复算关键公式，明确“股价冲击、转股价固定、债价目标固定”各自是假设还是事实；强赎/下修/回售、利息与信用变化均未进入机械情景。发现失真的券应降低模型权重，不增加小数位伪装精度。
2. 挑至少三组B内部冲突进行反方质询，例如“低溢价但大回撤”“高溢价但近面值与弱股债联动”“正股强、债券弱”。每组写 `B2支持什么 → B3挑战什么 → B1条款会改变什么 → 何种观察可裁决 → 暂定判断及最大反证`。必要时对A发一个**合流后**的发行人风险核验问题；G1前不把它变成B的依赖。
3. 对G1活跃候选，只有在B1核实票息、期限、到期现金流、转股价和关键条款后，才可做债底/YTM/更完整的期权或情景模型；输入不足时保留机械敏感性并明确不声称债底。交 `研究结论-v1.md`、模型假设表、冲突解释和逐券适用/不适用清单，供B负责人签认18行B诊断。

**可讲的真实切口：**若正股跌20%而债价仍维持T日水平，科沃转债 `SH:113633` 的候选溢价需比当下**再扩大约96.51个百分点**；帝欧转债 `SZ:127047` 则约需扩大25.38个百分点。这是“维持原价所需的条件”，不是说两个价格会这样走。科沃高溢价不能单独判负，帝欧低溢价也不能单独判正；B3风险和A侧信用证据会决定解释。

**PPT席位：**用敏感性图讲清楚一个结论的成立条件、最强反例和当前无法建模的部分。验收标准是公式可复算、18券覆盖、至少三组冲突被真正解释、正式方向没有被假设驱动的图表偷偷替代。
