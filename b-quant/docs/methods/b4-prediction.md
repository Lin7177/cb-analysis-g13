# B4 市场表现预测：方法说明

> 回答课程维度"市场表现预测"：给定T=2026-09-30的公开信息，未来约六个月
> （至2027-03-30）每券的持有收益**分布**是什么？该分布可信到什么程度？
> 本模块把既有B1定价核从"9个无概率情景点"升级为"可校验的分布陈述"，
> 是队长拍板的口径演进：旧版报告明示"不预测"，本模块给出模型化预测并自证其校准程度。

## 1. 业务问题 → 模型

| 问题 | 模型回答 |
| --- | --- |
| 正股半年后在哪，转债退出值多少？ | 历史block bootstrap（主引擎）：对该股真实日收益做126交易日块自助，块内保序保留波动聚集与跳空；10,000条路径 |
| 只用历史够不够稳健？ | GBM副引擎（σ取120日年化波动，零漂移为声明而非估计），与bootstrap并列 |
| 退出值怎么定？ | 退出价值曲面：复用B1定价核（QuantLib TF/CRR树，401步），在91个spot×3档利差上重估2027-03-30价值，路径终点插值（实测最大插值误差0.177元/百元面） |
| 溢价会不会收敛？ | 双口径并列：收敛口径（退出=模型值）与价差维持口径（退出=模型值×T日市价/模型价），真值大概率介于两者之间 |
| 期间现金流？ | 已核验合同现金流（58次真实除息口径）计入票息；末年兑付永不重复计 |

## 2. 输出schema（predictions.csv，103行）

每券×引擎{bootstrap,gbm}×退出口径{convergence,gap_persist}×利差{200,500bp}：
P5/P25/P50/P75/P95（退出价与收益率两套）、P(亏损)、P(>5%)、P(退出价>130强赎区域)、
均值、标准差。特例：乐歌到期兑付（确定性+0.11%）；翔26仅GBM（61条历史）。

## 3. 检验（walk-forward校准）

在6个历史词根（2021-09-30…2026-03-31，每年一次）只用词根前数据重建σ与自助池，
预测此后六个月分布，与真实结果对照（n=75，券×词根）：

- **覆盖率**：真实值落入P5–P95的比例 = **72.0%**（名义90%）→ 区间偏窄，模型过度自信；
  分词根看2023-09最差（53.8%）、2025-09最好（94.1%）。
- **PIT**：真实值在预测CDF中的位置偏离均匀（均值|PIT−50|=30.9个百分点）。

结论：**中枢可参考、区间偏乐观**——决策不得只看P50，必须并列P5与信用压力行。
这是我们把校准结果原样展示的原因：预测的可信度本身也是研究结果。

## 4. 决策影响（六案一致性）

| 券 | 预测分布特征（bootstrap/收敛/200bp） | 与六案的关系 |
| --- | --- | --- |
| 海顺(推荐) | P50 +4.0%，P5 −10.3% | 支持"有限配置倾向"；接受尾部 |
| 莱克(推荐-等待) | P50 +3.8%，价差维持口径仅+1.0% | 支持"等条件"：补偿偏薄 |
| 特纸(推荐-等待) | 收敛口径P50 −7.6% vs 价差维持−2.8% | 双口径分裂本身就是"T不买、等价格"的量化理由 |
| 科沃(不推荐) | 窄幅分布P50 −1.7%，P(亏损)96% | "补偿不足"而非"会大跌"；债性主导、对正股不敏感 |
| 帝欧(不推荐) | 收敛P50 +3.4% 但价差维持P50 −9.0%、P5 −21.8% | 中枢好看、尾部与口径全不合格 |
| 亿田(不推荐) | P50 +10.6% 但P5 −22.0%、P95 +85.6% | 分布最宽+尾部最深：高价依赖期权存续，P(亏损)34.7%、98.5%路径退出价仍>130 |

## 5. 边界（不可删除）

固定转股价（无滚动强赎/主动下修/回售）；利差为分析者情景；bootstrap有效样本小于路径数；
走查用T日条款与曲线回溯；退出值为模型参考非可成交价；收益为税费前。
manifest.json记录全部输入SHA-256与运行时版本，种子固定可复算。
