# 权重估计方法：全市场反推 + 两步决策法（B4 负责模块）

> **⚠ 版本说明（2026-10-03）**：本文档撰写于v1六维(D1-D6)口径下。维度体系已升级为S1-S6+M1/M2章程口径（见 `project_docs/维度体系章程.md`），当前生效权重以 `b-quant/results/weights/weights.json` 为准（S3信用与安全垫63%·S5路径流动性24%·S1基本面2%·S6预测7%·S4估值2%·S2正股判断1%）。本文的方法与文献部分仍然有效；文中D口径权重数字请勿再引用。



## 1. 问题与设计

六个评分维度（D1经营与信用 / D2估值可兑现 / D3债底保护 / D4股债传导 / D5路径与流动性 / D6前瞻分布）的**分数**由本组模型计算，**权重不由人设定**：从全市场可转债面板反推。数据与管线：

- 估计样本：全市场存续可转债面板（799只、2022-01-04～2026-07-31、1108个交易日快照），剔除本组18只研究券（纯样本外应用）、价格[85,260]元、剩余规模≥2亿元
- 特征（全部按"越高越好"定向，月末截面，winsorize 2.5/97.5 后 z-score）：评级序数、偿债能力（权益/总资产）、低溢价（-转股溢价率）、债底覆盖（保本价/市价）、正股联动（β×相关系数）、20日回撤、对数换手、损失频率（过去120个交易日窗口收益<-10%的占比，取负）、两因子分解残差（价格对"保本价+平价"回归的标准化负残差）
- 标签：未来约120个交易日的**回撤约束收益**——持有期内若路径回撤触及-15%即按-15%止损出场，否则取期末收益。这与本组委托（不加杠杆、重视下行、六个月窗口）一致；原始收益标签作为对照保留
- 方法：**Fama-MacBeth 月度截面回归**（43个月截面，Newey-West t，lag=6）+ **RankIC/ICIR**（月度Spearman秩IC的信息比率）双法互证；特征权重=两法归一化均值，按维度加总并归一

## 3. 关键发现与文献验证

**"低溢价因子≈0权重"不是bug**。三路独立文献查证（2026-10）：

1. 中国转债实证：信达证券《不一样的转债多因子》(2024-08)——转股溢价率"低IC、空头端更稳、多头收益被高估"；博时基金2025年报"传统双低策略有所失效"；2025-2026年高溢价偏股券领涨（高价债涨幅超正股）。机制：高溢价=市场对正股题材预期的定价（"平价较低时高转股溢价率本身表达了正股上涨预期"，《2026年转债定价方法报告》2026-09）+低溢价/双低策略拥挤透支。
2. 国际文献：premium/delta因子方向**regime依赖**——牛市股性券占优、信用收缩期债性券防御占优（2022年全球转债创2008以来最差、2024中国信用冲击后债底定价主导，与Tsiveriotis-Fernandes(1998)信用定价框架一致）。
3. 本组分年度Fama-MacBeth：债底覆盖四年全正（结构性规律），低溢价逐年翻符号（状态依赖）→ 权重给≈0是唯一不赌周期的选择。

## 4. 两步决策法（为什么推荐不是纯权重前三）

市场权重机械排序会把欧22/小熊排在海顺之前（债底覆盖更高）。但本组委托要求**兑现性**：溢价是持有者的"兑现税"，市场权重回答"风格如何被定价"，不回答"什么价格值得买"。故决策规则采用两步：

1. **补偿入围**（Graham & Dodd《Security Analysis》安全边际的量化版；模型参考≥市价，即树差≥0）：海顺(+4.91)、莱克(+2.75)直接进推荐池
2. **市场权重排序**（ICIR加权，Grinold & Kahn《Active Portfolio Management》；Qian, Hua & Sorensen《Quantitative Equity Portfolio Management》）：池不满三只时按综合分在非红线券中补足 → 特纸（5.61，开放券第一；树差-5故为"等待+条件"而非买入）

学术对应物：Gilbride & Allenby (2004, Marketing Science) 将"非补偿性筛选→补偿性排序"两步法正式建模；红线（评级下调/溢价>100%/期限样本）= 非补偿性筛选（Tversky 1972 elimination by aspects 传统）。红线券：江山/艾录/火星/亿田/帝欧（R1评级下调）、金23/志邦/蒙娜/科沃（R2溢价>100%）、乐歌/翔26（R3到期/样本）。

## 5. 局限（如实声明）

- 43个月短样本：各维度ICIR的排序差异统计上不可区分（Lewellen-Nagel-Shanken 2010; Harvey-Liu-Zhu 2016的多重检验背景），权重应视为"市场重要性区间"而非精确点估计——决策层因此用门槛+排序的两步法兜底
- FM斜率是"因子溢价"语义而非预测力语义（Barra传统），Shanken(1992)类修正式下显著性应打折
- 评级/偿债特征为当前快照，含少量前视；估计面板截至2026-07-31，应用端18券数据截至2026-09-30，存在两个月口径差（已声明）
- 分解残差特征逐年不稳（2024翻正），已从权重中剔除、保留于诊断
- 采集：评级快照来自东方财富公开接口（`bquant/collect/eastmoney.py`，可一键重跑）；行情面板由团队离线行情库导出（`bquant/market/catalog.py`适配器 + `scripts/b1_export_market_panel.py`，SHA-256清单随附）
