# B1｜数据、条款时点与价格结构

**交给这位成员的完整任务：**让另三位和最终报告都能在**同一日期、同一债券代码、同一条款版本**上研究；再解释18券当前价格由转股价值与其上方溢价如何构成。你是B1输入的唯一维护人，B负责人验收；姓名与复核人开工时填入。可自行安排检索工具，但不得把AI搜索摘要当原始公告。

**已有起点：**运行 `python work/B_methods/B1/run.py` 得到 [`base_v1.csv`](base_v1.csv)、[`terms_candidate_v1.csv`](terms_candidate_v1.csv) 和[价格结构图](price_structure_v1.png)。前者逐券列9月30日债/股收盘、样本长度、候选转股价、转股价值和溢价率；后者是公开数据接口在10月2日读取的候选快照。18/18债价、股价与T日公开日线一致，18/18转股价值及溢价公式与提供方一致。这是**候选条款核验**，不是发行人公告的生效日签认。

先看[三只真实债券的公告核验样板](公告核验样板.md)，再逐行填写[18券公告核验表 v0](逐券公告核验表_v0.csv)：它们展示怎样同时写明来源、有效日期、事件期限、对其他 B 模块的影响和**尚未完成的核验**。填完另存 v1，不能把样板的“已查公告”误记为全池签认。

**你要做的工作：**

1. 对18券逐一查T日前的发行人/交易所公告，确认9月30日**实际生效**的转股价与转股期；记录 `债券唯一键、候选转股价、核验转股价、公告名称/日期/链接或页码、生效日、核验人、状态、差异原因`。有调整公告但生效日在T之后的，不得提前使用。与 `base_v1.csv` 不一致时改出 `base_v2.csv` 并通知B2/B4重算。
2. 核对全池代码映射、9月30日收盘/成交量、数据缺口；补一页字段字典，明确债券每百元面值报价、正股不复权与前复权的各自用途、手数单位、停牌处理。翔26仅61条交易记录，必须标短样本。不得把本地库的停牌填充值混进公开交易日线。
3. G1前至少为拟入活跃池的券核对到期日、票息与到期现金流、强赎/回售/下修关键条款及未转股余额；全池其余券若暂缺这些字段，要留有逐券缺口，不能填零。真实成交额另核对来源，不能用收盘价乘手数冒充。
4. 写 `研究结论-v1.md`：说明全池转股价值和溢价的分布、至少一只“高溢价不必然是好/坏”的反例、条款调整如何改变计算，以及哪些券仍不能正式估值。给B负责人提交18行签认底表及官方出处。

**可讲的真实切口：**`SH:113633` 科沃转债候选溢价约286.02%，但T日债价约111.341、转股价值约28.843；不能只喊“溢价最高所以最贵”，需解释其债性、期限和信用保护。`SZ:127047` 帝欧转债候选溢价约1.53%，却不能仅凭接近平价就推荐；后续需B3和A核查风险。以上数字为候选口径，不是最终投资结论。

**PPT席位：**用价格结构图讲 `统一时点 → 计算转股价值/溢价 → 一个会误判的极端券 → 条款核验对结论的影响`。讲图表得出什么、不证明什么，不只报数据来源。验收标准是18行公告时点可追溯、公式可复算、异常可解释、下游知道哪些字段已经签认。
