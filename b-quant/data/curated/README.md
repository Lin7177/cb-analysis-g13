# 第13组 B 路线日频行情 v1

本目录的 `b_daily_group13_20200101_20260930.csv.gz` 是**公开采集**的研究底层行情：第13组18只可转债及其18只正股，从2020-01-01或各自上市首个交易日至统一观察日 **2026-09-30**。共36个标的、44,077条实际交易日记录，36个标的均有观察日收盘记录。逐券起止日期、条数、年度覆盖及文件 SHA-256 见同名 `manifest.json`。本数据由[采集脚本](../../scripts/b1_collect_daily.py)直接请求腾讯财经公开日 K 线接口；本地历史库仅用于独立交叉核验，没有向本文件补写记录。

| 字段 | 含义与用法 |
| --- | --- |
| `date`、`asset_key` | 北京市场交易日期、`SH/SZ:六位代码`；两列联合唯一 |
| `asset_type`、`bond_key` | `bond`/`stock`；正股行用 `bond_key` 连接对应转债 |
| `open/high/low/close` | 不复权日价；转债为每百元面值报价、正股为每股人民币报价。观察日转股价值必须用**不复权**正股收盘价和当日有效转股价计算 |
| `volume_lots` | 行情接口原始“手”数；债券一手通常为10张、股票一手通常为100股。股票按整手显示，与精确股数可能相差不足一手；不可当作精确股数或实际成交额 |
| `qfq_open/high/low/close` | 仅正股填前复权日价，供历史收益率、波动和联动性分析；转债为空。前复权历史值会随日后除权事件重算，故本文件以采集时间快照与校验和固定版本 |

价格、风险和流动性比较应先按 `bond_key` 对齐，再按 `date` 做交集；不要将停牌日机械补成一条零收益交易记录。样本中的永吉转债 `SH:113646` 在 2022-05-19 至 2022-05-25 停牌核查，公开日线没有这五条，复牌日为 2022-05-26（[停牌公告](https://www.xinbaomu.com/info/35783.shtml)、[复牌公告](https://www.xinbaomu.com/info/37989.shtml)）。本地历史库对这些日期有“前收盘价+零成交量”的填充值；本文件未引入它们。翔26转债 `SH:113703` 到观察日仅61条交易日记录，不能硬套需要更长历史的模型，应明确降级。

复现：在 `b-quant/` 目录运行 `python scripts/b1_collect_daily.py`；只验收已有文件运行 `python scripts/b1_collect_daily.py --validate-only`（注：脚本内全池清单路径仍指向老仓库布局，修复前仅 `--validate-only` 可完整工作）。需 Python `requests`，输出是标准 gzip CSV。脚本逐年请求公开接口，缓存放在被 Git 忽略的 `data/cache/`，正式数据和清单在本目录纳入版本管理。已验收：36/36观察日有记录、联合键无重复、OHLC及正股复权日期通过程序检查；与本地历史库 2026-07-31 的36组重叠记录比较，价格全部一致，成交量在来源计量/取整差异内一致。

此处仅承诺**日频价格和成交量**。实际成交额、当日有效转股价、未转股余额、评级、条款与财务信息不由此接口提供，须在 B1 底表另采并注明来源；不得用价格推算值冒充实际成交额。所有投资判断仍以共同投资问题和2026-09-30的信息截止为准。
